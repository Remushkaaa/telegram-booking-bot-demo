# Telegram-бот запису клієнтів (демо)

Бот для майстра/студії: клієнт сам обирає послугу, день і вільний час, бот не дає записати двох людей на одну годину.

## Можливості
- Вільні слоти рахуються за тривалістю послуги та робочим днем (10:00–19:00), минулий час і зайняті проміжки не показуються.
- Запис: послуга → день (7 днів) → час → імʼя й телефон з перевіркою. Майстру приходить сповіщення.
- `/my` — мої записи з відміною (чужі записи скасувати не можна).
- `/schedule` — розклад майстра на сьогодні (тільки для адміна).
- Нагадування клієнту за добу, без повторів.

## Запуск
```
pip install -r requirements.txt
set BOT_TOKEN=токен_від_BotFather
set ADMIN_IDS=ваш_telegram_id
python bot.py
```
Послуги додаються методом `Booking.add_service(name, minutes, price)` (або командою адміна за потреби).

## Тести
`pytest` — 7 тестів: слоти, перетини, подвійний запис, минулий час, відміна, нагадування і наскрізний сценарій у Telegram на підміненій сесії.

Стек: Python 3.13, aiogram 3, SQLite.
